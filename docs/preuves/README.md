# Preuves

Sorties de commandes brutes, rangées par semaine. Les captures d'interfaces
graphiques sont dans [`../screenshots/`](../screenshots/), les fichiers de
configuration déployés dans [`../../configs/`](../../configs/).

Nommage : `sNN-NN-<sujet>.txt`, dans l'ordre chronologique de la semaine.
Chaque fichier commence par la date, la machine et la commande exécutée.

Les adresses IP publiques (IPv6), l'adresse VPN et tout secret sont masqués.
